# Copilot Learning Launchpad

Static GitHub Pages export of a managed app, customized into a clean-slate Copilot LMS experience.

## Customizations

- Browser-local learner account creation.
- Device-local progress, bookmark, resume, weekly-minute, and reset controls.
- Community section intentionally blank until real learner activity exists.
- Synthetic community highlights, leaderboard links, admin links, company/persona framing, and prefilled learner messaging removed or softened.
- Messaging repositioned around learning Copilot rather than workplace/company adoption.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. In GitHub, open **Settings > Pages**.
3. Set **Source** to **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`.

The site is a single-page app, so `404.html` intentionally mirrors `index.html` for direct route support.
